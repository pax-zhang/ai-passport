# 农场（本固件）

[English](APPS.md) | 简体中文

本镜像是**独立农场游戏固件**，开机即田地，不含通知、对讲机、天气、验证器。**语言、Wi-Fi、蓝牙、时钟、屏幕、声音、玩家 ID、固件更新都在游戏里设置**，不必先刷 `main`。固件刷入后第一次开机 toast「长按确定全局返回」。

引脚和 BSP 边界见 [README.zh_CN.md](../README.zh_CN.md) 与 [AI 硬件开发指南](AI_HARDWARE_DEVELOPMENT_GUIDE.md)。

配套服务端在 `server/`（Next.js + MySQL）。设备固定连 `https://farm.netbiu.com`，设置里不能改。本地联调改 `APP_FARM_HOST_DEFAULT` 后重新编译。浏览器打开该地址可点「生成假农场」，写入 24 个可偷、可排行的假账号（`900001` 起），不覆盖真机。

贴纸在 Ardot 里画，**不要背景**，导出 **PNG**，再执行 `python3 scripts/png_to_lvgl.py` 导入。说明见 `assets/farm/README.md`。

## 按键

三键 `UP` / `DOWN` / `OK` 共用 GPIO0 的 ADC 分压。

| 操作 | 效果 |
| --- | --- |
| 短按 `UP` / `DOWN` | 底栏在主页 / 背包 / 偷菜 / 设置之间移动；进页后在该页动作或地块间移动 |
| 短按 `OK` | 进入当前页。主页先选工具再选地块。种子键弹出图标框，上下选已有种子再确定。背包购买或选中种子。偷菜：随机做客、好友、排行。设置打开高亮项 |
| 长按 `OK` | 退出选地、好友操作、设置子页、做客或键盘 |
| 长按 `UP` / `DOWN` | 背包切换物品 / 商城；偷菜切换随机 / 好友 / 排行。键盘里按住会连移，再按住就按行跳 |
| 蓝牙配对码 | `OK` 确认，`DOWN` 拒绝 |
| 息屏时任意键 | 唤醒（第一次点击会被吃掉） |

顶部是农场名、等级、金币、本地时间和电量。Wi-Fi 开着时画一个小图标。

## 主页

六个工具：种子、种植、浇水、除草、除虫、收获。确定工具后再上下选地、再确定。种子先弹出类别，选好后立刻进入选地种植。选地时跳过不能做该操作的地块；一块都不能做时提示「无地块种植」「无需除草」等。

| 工具 | 作用 |
| --- | --- |
| 种子 | 弹出图标框选已有种子，确定后进入空地种植 |
| 种植 | 在空的已解锁地块上消耗 1 颗种子，种下后缺水 |
| 浇水 | 开始生长计时 |
| 除草 / 除虫 | 清掉对应灾害；有草或虫时不能收获 |
| 收获 | 成熟且干净的地块换成金币和经验 |

开局 6 块地、80 金币、4 颗胡萝卜种子。3 级 9 块地，6 级 12 块地。作物：胡萝卜 / 白菜（1 级）、番茄（3）、玉米（5）、草莓（8）、西瓜（12）。不浇水不长。地里的作物可能长草生虫。断电追赶最多 8 小时。

## 背包

长按上下切换物品 / 商城。物品列出已有种子（确定选中种植种子）。商城列出全部作物，未解锁的显示等级，确定买 1 颗。

## 偷菜

需要 Wi-Fi 和服务器地址。长按上下切换随机 / 好友 / 排行。

| 分页 | 作用 |
| --- | --- |
| 随机 | 确定寻找最近活跃的别人农场（优先有熟菜的）。界面像主页，工具变成手。在成熟地块上确定，偷到约 60% 收获金币。长按确定离开。每人每天最多 10 次；同一目标 10 分钟内最多偷 2 次 |
| 好友 | 上方是邀请（确定同意，长按下键拒绝）。然后是好友（确定 → 进入 / 删除）。最后一行是添加（输入 6 位 ID） |
| 排行 | 按金币排序。确定后只能参观（不能偷、不能帮） |

别人偷走你的熟菜后，下次同步会提示菜被偷了。

## 设置

随时可进。

| 页 | 作用 |
| --- | --- |
| 语言 | English / 简体中文（默认），写入 NVS |
| ID | 由 Wi-Fi STA MAC 用 FNV-1a 算出的 6 位数字，与服务端同一公式 |
| Wi-Fi | 开关、自动重连、扫描、加入（三键密码）、忘记 |
| 蓝牙 | 开关、安静、广播、忘记绑定 |
| 日期和时间 | NTP 开关（默认开）和服务器。关掉 NTP 后拨时再**对时** |
| 屏幕 | 亮度 10–100%；自动休眠 永不 / 15 / 30 / 60 / 120 秒。在屏幕页或主界面等到时限就会息屏 |
| 声音 | 静音；音量 0–100% |
| 更新 | 当前和最新版本；检查；确认后安装 |
| 重置农场 | 清空田地、种子和金币，保留 ID、令牌和服务器 |

状态存在 NVS（`app` / `farm`）。OTA 通道是 `demo/farm`。

## 服务端

`POST /api/register` 用 MAC 绑定并计算 ID，再发令牌。之后请求带 `Authorization: Bearer <token>`。`PUT /api/farm` 上传本地农场，`GET` 拉回被偷的地。随机 / 做客 / 偷菜 / 好友 / 邀请 / 排行都在 `/api/` 下。

## 设备息屏

到达设置里的自动休眠时间后（0 为永不）：背光关、屏幕睡、射频关。按键唤醒。亮屏满 30 秒才恢复 Wi-Fi。屏幕 / 声音页也会按时息屏。键盘、做客、联网任务、正在安装固件、蓝牙配对码，或 Wi-Fi / 蓝牙 / 时钟 / 更新页忙碌时才推迟。
